- `git remote` allows you to manage your remote repositories:
```
git remote
```
- `git remote -v` allows you to see more information about remote as *remote URL*:
```
git remote -v
```
- `git remote show <name>` gives information about an specific remote repository:
```
git remote show <name>
```
- `git remote update` takes updates from all remotes:
```
git remote update
```
- `git branch -r` lists all remote branches:
```
git branch -r
```
- `git remote add <remote-name> <address>` adds a remote:
```
git remote add dev github.com\0000000
```
