### Syntax:
```
SELECT * FROM table_name ORDER BY something;
```

For example:
```
SELECT * FROM person ORDER BY country_of_birth;
```

>**Note:** The default in `ORDER BY` selection is `ASC` (stands for ascending); Also can be change to `DESC` (stands for descending).

`ASC` and `DESC` are used for order from first to last and vice versa.

For example:
```
SELECT * FROM person ORDER BY id DESC;
```
