The `INSERT` statement is used to populate a table with rows:

![pic-3](PostgreSQL/Summary%20of%20PostgreSQL%20Official%20Documentation/imgs/3.png)

The syntax used so far requires you to remember the order of the columns. An alternative syntax allows you to list the columns explicitly:

![pic-4](PostgreSQL/Summary%20of%20PostgreSQL%20Official%20Documentation/imgs/4.png)

You can list the columns in a different order if you wish or even omit some columns, e.g., if the precipitation is unknown:

![pic-5](PostgreSQL/Summary%20of%20PostgreSQL%20Official%20Documentation/imgs/5.png)

Many developers consider explicitly listing the columns better style than relying on the order implicitly.
