
```
\?
```

---
#### How to clear `psql` terminal screen?
- **Keyboard Shortcut**: Press **Ctrl+L**.  This is the most common and efficient method on **Linux** and **Mac**. On **Windows**, if Ctrl+L does not work, try **Ctrl+Shift+L**.
- **Meta-Command**: Type **`\! clear`** (on Linux/Mac) or **`\! cls`** (on Windows) and press Enter.
