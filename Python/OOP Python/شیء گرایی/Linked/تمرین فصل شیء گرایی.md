کلاسی بنویسید با نام Dog که نام و سن را به عنوان ورودی دریافت کند. درون این کلاس یک class variable بسازید که با هر بار ساخته‌شدن یک instance یک واحد به آن اضافه شود و نام این متغیر را quantity بنامید.

راه حل من:
```
class Dog:
	quantity = 0
	def __init__(self, name, age):
		self.name = name
		self.age = age
		Dog.quantity += 1 # you should tell that it is class's variable.

dog1 = Dog("Alex", 1)
dog2 = Dog("Sushi", 3)

print(Dog.quantity)

# output:
2
```
