ساخت یک کلاس در پایتون با کلید واژه Class آغاز می‌شود که می‌تواند اسم و اطلاعات دیگری به همراه داشته باشد.

یک object که مبتنی بر کلاس ایجاد می‌شود فضایی از حافظه را به خود تخصیص می‌دهد. هر ویژگی (Attribute) که به آن شیء داده شود، فقط در همان فضای مشخص، ذخیره شده و اشغال می‌کند.

یک مثال از اینکه Attribute های یک شیء چه هستند و در کجا قرار دارند:
```
class Employee:
	def __init__(self, name, age, salary):
		self.name = name
		self.age = age
		self.salary = salary
```
ویژگی‌ (attribute) های یک شیء ساخته شده، self.name ,self.age ,self.salary هستند.
