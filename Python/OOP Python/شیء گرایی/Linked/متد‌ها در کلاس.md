متد، عملیاتی است که به یک کلاس نسبت می‌دهیم. این متد می‌تواند مبتنی بر کلاس یا بدون ایجاد یک object ، از خود کلاس نشأت بگیرد و اجرا شود.

بطور کلی یک متد، برای کلاس است -  اگر یک متد مربوط به کلاس می‌نویسید:
```
class Employee:
	def __init__(self, name, age):
		self.name = name
		self.age = age

	def greetings():   # class method
		return "Hello"

print(Employee.greetings())
# which means: from Employee class, run greetings method.
```
اما اگر یک متد مبتنی به یک object می‌نویسید، باید پارامتر object را به متد بدهید؛ که پارامتر آن، self (یا هر اسم دیگری می‌تواند باشد به شرطی که در همه جا یکسان باشد) است. مانند:
```
class Employee:
	def __init__(self, name, age):
		self.name = name
		self.age = age

	def greetings(self):  # object method
		return f"Hello {self.name}"

emp1 = Employee("Milad", 22)
print(emp1.greetings())

# output:
Hello Milad
```
پس اگر بجای کد بالا از متدی که برای شیء است (که شیء برای کلاس است) از متد شیء بعنوان متد کلاس استفاده کنیم، خطا خواهد داد:
```
class Employee:
	def __init__(self, name, age):
		self.name = name
		self.age = age

	def greetings(self):  # object method
		return "Hello"

print(Employee.greetings()) # calls a class method that doesn't exist
```
همانطور که گفته شد، خطا به این دلیل رخ می‌دهد زیرا ما یک متد کلاسی را صدا می‌زنیم که وجود ندارد و آن متدی که به اشتباه منظور ما همان است، درواقع متد object است نه متد کلاس؛ به این دلیل خطا دریافت خواهد شد.

پس به اینکه متد، برای کلاس است یا object، باید دقت شود. اگر متد برای object باشد، باید پارامتر self را که مشخه آن است، دریافت کند.

نکته: متد چه برای کلاس و چه برای object ، می‌تواند پارامتر‌های مستقل صرفا برای خود ، دریافت کند. 
مثال از پارامتر مستقل از شیء برای متد object:
```
class Employee:
	def __init__(self, name, age):
		self.name = name
		self.age = age

	def greetings(self, country): # object method
		return f"Hello {self.name} from {country}"

emp1 = Employee("Milad", 22)
emp2 = Employee("Faraz", 22)

print(emp1.greetings("Iran"))
print(emp2.greetings("Germany"))

# output:
Hello Milad from Iran
Hello Faraz from Germany
```

مثال از پارامتر مستقل از شیء برای متد کلاس:
```
class Employee:
	def __init__(self, name, age):
		self.name = name
		self.age = age

	def greetings(country): # class method
		return f"Hello from {country}"

print(Employee.greeting("Iran"))
# which means: from Employee class, run greetings method.

# output:
Hello from Iran
```

---
نکته:
>**فراخوانی با `self`:** در پایتون، وقتی می‌خواهی یک متد از همان کلاس را داخل متد دیگر صدا بزنی، حتماً باید از `()self.method_name` استفاده کنی.
