**Debug** (or **debugging**) means **finding and fixing problems (bugs) in a program or system**.

A _bug_ is any mistake that causes software to behave incorrectly — like crashing, giving wrong results, or not responding as expected.

### In simple terms:

- **Bug** → something is broken
    
- **Debugging** → figuring out _why_ it’s broken and fixing it
    

### Examples

- A program crashes → you debug to find the line causing the crash
    
- A website shows wrong data → you debug to see where the logic failed
    
- A command returns an error → you debug by checking inputs, logs, or responses
    

### Common debugging methods

- **Printing values** (e.g., `print()` or `console.log()`)
    
- **Using a debugger** (step through code line by line)
    
- **Checking logs**
    
- **Testing with different inputs**
    
- **Reproducing the bug consistently**
    

### Example (simple)
```
x = 10
y = 0
print(x / y)   # crash → debug by checking why y is zero
```

Debugging is a normal, constant part of programming — even professional developers spend a large portion of their time doing it.
