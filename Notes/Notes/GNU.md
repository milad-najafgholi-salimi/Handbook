GNU is a **free software project and operating system** started in **1983** by **Richard Stallman**, with the goal of creating a **completely free, UNIX-compatible operating system**.

The name **GNU** is a recursive acronym:

> **GNU’s Not Unix**

---

## 1. Why GNU Was Created

In the early 1980s:

- UNIX was becoming **proprietary**
    
- Programmers were no longer allowed to study, modify, or share source code
    
- Richard Stallman believed this restricted user freedom
    

So he started the **GNU Project** to create:

> A complete UNIX-like system that anyone could use, modify, and share freely.

---

## 2. What GNU Actually Provides

GNU created **almost everything needed for an operating system**, except one critical part at first — the kernel.

### Major GNU components include:

- **GCC** – GNU Compiler Collection
    
- **glibc** – the standard C library
    
- **bash** – the shell
    
- **coreutils** – commands like `ls`, `cp`, `mv`, `cat`
    
- **grep**, **awk**, **sed**
    
- Development tools, debuggers, documentation tools
    

So when you type common commands on a Linux system, most of them are actually **GNU programs**, not Linux ones.

---

## 3. What GNU Was Missing: The Kernel

GNU started its own kernel project called **Hurd**, but:

- It was very ambitious
    
- Development was slow
    
- It never became widely usable
    

Then in 1991:

- **Linus Torvalds released the Linux kernel**
    
- Linux worked well with GNU tools
    

Together they formed a complete OS:

> **GNU + Linux = a full operating system**

This is why some people insist on calling it **GNU/Linux**.

---

## 4. GNU vs Linux (Clear Difference)

|Component|GNU|Linux|
|---|---|---|
|What it is|Collection of system tools + philosophy|Kernel|
|Role|Userland + compilers + utilities|Hardware & process control|
|License|GNU GPL|GNU GPL|
|Created by|Richard Stallman|Linus Torvalds|

Linux alone cannot do much without GNU tools.

---

## 5. Free Software Philosophy

GNU is not just technical—it’s **philosophical**.

It promotes **four essential freedoms**:

1. Run the program for any purpose
    
2. Study how it works
    
3. Modify it
    
4. Share it (with or without changes)
    

This philosophy shaped modern open-source development.

---

## 6. Why You Often Hear “Linux” Instead of “GNU/Linux”

- Shorter and easier to say
    
- Popularized by media and companies
    
- But technically incomplete
    

From a strict technical standpoint:

> Most “Linux” systems are actually **GNU/Linux** systems.

---

### In one sentence:

**GNU is the free software foundation and toolset that, combined with the Linux kernel, forms the operating system most people call “Linux.”**
