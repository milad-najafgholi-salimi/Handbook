# Machine Learning Algorithms
There are two types:
- Supervised Learning
- Unsupervised Learning
- Reinforcement Learning

مدل Supervised Learning در دنیای واقعی خیلی بیشتر استفاده میشه و پیشرفت‌های عظیمی داشته. 

اطمینان از اینکه ابزار رو دارید مهمه اما اینکه بتونید چطور از این ابزار استفاده کنید و اون‌ها رو پیاده کنید به مراتب مهم‌تره. 

یادگیری نظارت شده (Supervised Learning) همان نظارت بر ورودی‌ها و خروجی‌هاست. 


---
رگرسیون با استفاده از داده‌ها و یک مدل (استفاده از توابع) یک خروجی پیوسته (نه گسسته) می‌دهد که می‌تواند با داده‌هایی که بعنوان ورودی گرفته است، خروجی را پیشبینی کند.

متغیری که می‌خواهیم پیشبینی کنیم متغیر وابسته می‌باشد. متغیر یا متغیرهایی که باعث می‌شوند بر اساس آن‌ها پیشبینی انجام دهیم را متغیرهای مستقل می‌گویند.

متغیرهای مستقل می‌توانند از نوع پیوسته یا گسسته باشند.
