بطور کلی هرچقدر به یک الگوریتم یادگیری فرصت بیشتری برای یادگیری بدهید عملکرد بهتری خواهد داشت.
دو نوع اصلی یادگیری ماشین، یادگیری نظارت شده (Supervised Learning) و یادگیری بدون نظارت یا یادگیری نظارت نشده (Unsupervised Learning) است.
از بین این دو، یادگیری نظارت شده نوعی از یادگیری ماشین است که بیشتر در خیلی از کاربردهای دنیای واقعی استفاده می‌شود و شاهد سریع‌ترین پیشرفت‌ها و نوآوری‌ها بوده.
نوع دیگر از الگوریتم‌های یادگیری ماشین، یادگیری تقویتی است.
امروزه دو نوع از الگوریتم‌های یادگیری که بیشترین استفاده را دارند، یادگیری نظارت شده و یادگیری نظارت نشده است.
