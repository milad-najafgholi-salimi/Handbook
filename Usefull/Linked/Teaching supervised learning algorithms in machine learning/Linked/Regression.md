**رگرسیون (Regression)** یکی از شاخه‌های اصلی یادگیری نظارت شده (Supervised Learning) است که برای **پیش‌بینی مقادیر عددی پیوسته** استفاده می‌شود.

به زبان ساده، وقتی می‌خواهیم خروجی یک عدد باشد (مثل قیمت، دما، سن، یا وزن)، از الگوریتم‌های رگرسیون استفاده می‌کنیم.

### تفاوت کلیدی با دسته‌بندی (Classification)

- **رگرسیون:** خروجی **عدد** است. (مثلاً قیمت خانه: ۳۵۰ میلیون تومان)
    
- **دسته‌بندی:** خروجی **گروه یا کلاس** است. (مثلاً سالم یا بیمار، گربه یا سگ)
    

### مثال‌های واقعی از رگرسیون:

1. **پیش‌بینی قیمت مسکن** بر اساس متراژ، سال ساخت و موقعیت مکانی.
    
2. **پیش‌بینی دمای هوا** برای فردا بر اساس داده‌های هواشناسی.
    
3. **پیش‌بینی فروش یک محصول** در ماه آینده.
    
4. **پیش‌بینی سن یک فرد** بر اساس عکس (در برخی نرم‌افزارها).
    

### الگوریتم‌های معروف رگرسیون:

- **رگرسیون خطی (Linear Regression):** ساده‌ترین نوع، که رابطه خطی بین ورودی و خروجی را پیدا می‌کند.
    
- **رگرسیون چندجمله‌ای (Polynomial Regression):** برای روابط منحنی شکل.
    
- **رگرسیون ریج (Ridge) و لاسو (Lasso):** برای جلوگیری از بیش‌برازش (Overfitting).
    
- **درخت تصمیم و جنگل تصادفی (Decision Tree & Random Forest):** که قادر به مدل‌سازی روابط غیرخطی هستند.
    
- **رگرسیون بردار پشتیبان (SVR):** نسخه رگرسیون SVM.
    

### خلاصه:

اگر مسئله شما این است که **"چقدر؟"** یا **"چه مقدار؟"** بپرسید، به رگرسیون نیاز دارید.  
اگر مسئله شما **"کدام دسته؟"** است، به دسته‌بندی نیاز دارید
