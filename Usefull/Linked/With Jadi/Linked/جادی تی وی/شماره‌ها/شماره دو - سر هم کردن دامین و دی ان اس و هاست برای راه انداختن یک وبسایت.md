**تمام دنیای کامپیوتر تمرین، خواندن، تجربه کردن، حوصله کردن و یاد گرفتن است.**

برای راه اندازی یک سایت باید یک Domain خریداری کنید. سپس آن را به یک Host متصل کنید و یک سرویسی را ارائه دهید که وب، مرسوم‌تر است.

سرویسی که Domain را به Host (که برای ما با یک IP بر روی هاست ذخیره شده) متصل می‌کند، DNS Server (مخفف شده Domain Name System server) می‌گویند.

ما با اسم‌ها کار می‌کنیم. برای مثال jadi.net ؛ اما اینترنت با IP ها کار می‌کند (که یک عدد چهار بخشی مانند `198.74.56.50` است. IP ها یکتا هستند که هر کدام از بخش‌های این IP از صفر تا ۲۵۵ است).

ما در صفحه مرورگر خود، jadi.net را تایپ می‌نیم. jadi.net از DNS server می‌پرسد که IP آن چیست؛ عدد `198.74.56.50` جواب داده می‌شود (به ما بر می‌گرداند). حال ما IP را داریم و مرورگر ما به آن IP می‌رود؛ اینکه چگونه می‌رود، مربوط به بحث Network است. 

پس ما یک Domain می‌خریم. سپس یک DNS server پیدا می‌کنیم که گاهی سرویس دهنده‌های مستقل و گاهی Host ها ارائه می‌دهند. در DNS server می‌گوید که jadi.net دارای IP = `198.74.56.50` است. 

دستور زیر در ترمینال یک packet به سایت ارسال می‌کند که می‌پرسد آیا آنجایی؟ و جواب را به طور مداوم بر می‌گرداند:
```
ping jadi.net
```

دستور زیر اطلاعاتی در مورد Domain نشان می‌دهد:
```
whois jadi.net
```
نگاه می‌کند که DNS از کدام سایت است.

دستور زیر هم جالب توجه است - `nslookup` مخفف شده‌ی name server lookup است:
```
nslookup jadi.net
```
