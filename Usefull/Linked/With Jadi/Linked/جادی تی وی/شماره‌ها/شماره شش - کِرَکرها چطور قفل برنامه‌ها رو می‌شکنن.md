دستور file یک ابزار بسیار کاربردی برای تشخیص نوع واقعی یک فایل (هر چیزی می‌تواند باشد) است.
```
file something
```
برای دیدن اطلاعات بیشتر درمورد دستور file، از `file --help` استفاده کنید.
یا اینکه از `man file` استفاده کنید.

به محل فایل اجرایی مورد نظر که قصد کرک داریم می‌رویم و با دستور 
```
file ...
```
اطلاعات بسیار مفیدی بدست می‌آوریم که نشان می‌دهد با چه فایلی روبرو هستیم. 
برای مثال می‌خواهیم فایل اجرایی pass را که به زبان ماشین نوشته شده است را کرک کنیم.
اگر آن را به صورت `cat pass` بخوانیم، چون به زبان ماشین نوشته شده، متن قابل فهمی را نشان نمی‌دهد. می‌توانیم آن را به صورت hex که زبان ماشین است بخوانیم. از دستور زیر کمک می‌گیریم:
```
hexdump -C pass | less
```
دستور `less` برای آن است که صفحه به صفحه ببینیم و یهو یک عالمه متن تحویل ما ندهد و مموری ما را اشغال نکند. 

در مورد فِلگ (flag) `c-` می‌توانی با دستور `hexdump --help` اطلاعات کسب کنی.

روش ساده‌تر آنکه می‌توانیم از دستور زیر استفاده کنیم تا جملاتی که برای انسان‌ها قابل درک است را نمایش دهد:
```
string pass | less
```

اما یک برنامه نویس حرفه‌ای برای جلوگیری از دستیابی کِرَکرها (یا هکر‌ها) آن را به احتمال زیاد Hash می‌کند.
چه کنیم؟ برنامه‌ای به نام `objdump` وجود دارد که برای کسب اطلاعات می‌توانی از `man objdump` یا `objdump --help` استفاده کنی. 
فِلَگ (flag) `S-` آن را به source اسمبلی تبدیل می‌کند. (اسمبلی زبانی است که خیلی به زبان ماشین نزدیک است.)

در صفحه‌ای که با `man` باز شده است، برای جست‌وجوی عبارت خاصی از `/` استفاده می‌کنیم. برای مثال `C-/` به دنبال عبارت `C-` می‌گردد و آن را هایلایت می‌کند.
با `/` و زدن Enter می‌توانی به آن بخش وارد شوی و درمورد مثلا `C-` بطور مفسل‌تر بخوانی.

دستور `objdump` فلگ‌های زیاد و خیلی مفیدی دارد.

```
objdump -S -l -C -F -w pass | less
```
نکته:
۱) pass همان نام فایلی بود که قصد کرک آن را داشتیم.
۲) درمورد هر کدام از این سویچ‌ها می‌توانی جداگانه در `man` مربوطه یا `help--` آن مطالعه کنی.

بعدش واسه اینکه بتونید از خروجی سر در بیارید باید یک ذره اسمبلی بلد باشید. 

#### خوب است بدانی:
دستور 
```
md5sum pass
```
هش مربوط به فایل را می‌دهد.
اگر یک کپی از آن بگیری و هش‌ها را مقایسه کنی، هش‌ها یکسان خواهد بود:
```
cp pass crack
md5sum crack
md5sum pass
```

دستور `* md5sum` (که `*` یک wildcard است) هش همه‌ی فایل‌های دایرکتوری که در آن قرار داریم را می‌دهد.
