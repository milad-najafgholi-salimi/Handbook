Basically, a relation is just a connection between data.

A relational database, is a table that data can interact or speak together. 

For example, Data in a row can have multiple columns (called **Attribute(s)**) that are related together. Each data in a row, connected to each column in the same row.
This called Relational Data; So if we had a bunch of data like this one, it will be a Relational Database (that, each data is in a same table).
